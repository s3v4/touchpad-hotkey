# Touchpad Hotkey

Включение и отключение тачпада по **Ctrl + Alt + Пробел** в Windows.

Небольшая утилита на C# с иконкой в области уведомлений. Она использует встроенную команду Windows Precision Touchpad `Ctrl + Win + F24`; драйверы и права администратора не требуются. При запуске текущее состояние тачпада сохраняется.

## Совместимость

- Windows с Precision Touchpad и .NET Framework 4.x.
- Включение и отключение проверены на Xiaomi Book Pro 14 (2026) с Windows 11.
- На других ноутбуках совместимость пока не проверена.
- Сочетание фиксированное. Fn + Пробел не настраивается этой программой.
- На защищённом рабочем столе, например при запросе UAC, сочетание не работает.

## Сборка

Откройте PowerShell в папке проекта и выполните:

```powershell
.\build.ps1
```

Скрипт использует компилятор .NET Framework из Windows и создаёт `bin\TouchpadHotkey.exe`. Скачивание зависимостей не требуется.

## Запуск и установка

Для разового запуска откройте `bin\TouchpadHotkey.exe`.

Для установки в профиль пользователя с автозапуском выполните:

```powershell
.\install.ps1
```

Программа будет скопирована в `%LOCALAPPDATA%\TouchpadHotkey`. При следующем входе в Windows она запустится автоматически. Если уже запущена другая копия, сначала выберите «Выход» в меню её значка.

Нажмите **Ctrl + Alt + Пробел** и отпустите клавиши: тачпад переключится. Повторное нажатие вернёт его в предыдущее состояние. Программа ждёт отпускания клавиш, чтобы Alt не попал во встроенную команду Windows.

Через меню значка можно открыть настройки тачпада или завершить программу. Журнал `TouchpadHotkey.log` записывается рядом с EXE и содержит время запуска и отправки команды. Журнал не входит в репозиторий.

## Удаление

1. Выберите «Выход» в меню значка программы.
2. Удалите `TouchpadHotkey.lnk` из папки автозагрузки пользователя.
3. Удалите папку `%LOCALAPPDATA%\TouchpadHotkey`.

Если нужно вручную включить тачпад: **Параметры → Bluetooth и устройства → Сенсорная панель**.

## Проверка

Исходник компилируется штатным компилятором .NET Framework. На проверенном ноутбуке после первого нажатия состояние Windows менялось с `Enabled=1` на `0`, после второго — обратно на `1`. Успешная отправка команды не гарантирует поддержку на каждом устройстве.

## Как это работает

`RegisterHotKey` регистрирует `Ctrl + Alt + Space` с подавлением автоповтора. После отпускания клавиш `SendInput` отправляет системную команду переключения. Повторный запуск блокируется именованным mutex.

Документация Microsoft: [Enable/Disable Toggle Button](https://learn.microsoft.com/en-us/windows-hardware/design/component-guidelines/touchpad-enable-or-disable-toggle-button).
